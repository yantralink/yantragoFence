# YantraGO — 60-Second Silent Advertisement Script
## For TV Display at Krushi Pradarshani (Agriculture Exhibition)

**Format:** Silent video — all communication via on-screen text + visuals
**Duration:** 60 seconds (loops on TV)
**Language:** Marathi (primary), English (support line) — audience is farmers
**Tool:** Canva (use "Video" template, 1920×1080 for TV)
**Brand color:** #0B65C2 (blue), white text, green accents (#2E7D32) for farm feel

---

## Scene-by-Scene Script

### SCENE 1 — The Problem (0:00 – 0:07)

**Visual:** Night footage / stock clip of wild boar, nilgai (नीलगाय), or stray animals entering a farm field at dusk. Dark tone. Crop damaged shots.

**Canva tip:** Use "Fade in" text animation. Dark overlay (40% black) behind text so it reads on any footage.

## Production Notes for Canva

### Timing
- Each scene = one Canva "page". Set page duration as listed above (right-click page → "Edit timing").
- Total must add to exactly 60s for a clean loop.

### Text rules (silent video = text IS the voiceover)
- **Max 2 lines on screen at once.** Farmer audience = keep Marathi text big (min 60pt on 1080p).
- Marathi headline bold + English line smaller, italic, below.
- Never put text in the bottom 10% or top 10% of the frame (TV safe zones — some TVs crop edges).
- Use Canva fonts with good Devanagari support: **Mukta**, **Noto Sans Devanagari**, or **Hind**.

### Visual style
- Farmer/trust feel: greens, sky blues, real farm photos — avoid corporate stock people in suits.
- Transitions: only "Dissolve" or "Slide". No flashy spins — trust-building product.
- Phone mockups: Canva elements → search "phone mockup", insert app screenshots inside.
- QR code: Canva Apps → "QR Code" generator → link to Play Store listing.

### Assets you'll need before building
1. App screenshots: map screen, machine detail (voltage/battery), alerts inbox, ON/OFF toggle, weather widget — capture on a real device in **Marathi** locale if possible.
2. Product photo of the Zhatka machine (use the one from the proposal doc).
3. YantraGO logo PNG with transparent background.
4. Stock clips of wild animals in fields (Canva's built-in stock library — search "wild boar farm night").
5. QR code pointing to Play Store link.

### Optional finishing touches
- Subtle background music is NOT needed (silent requirement) — but add a soft "whoosh" sound effect on text transitions only if the TV will have audio; skip if truly silent.
- Add a thin progress bar at the bottom showing time — subconsciously keeps viewers watching.
- End the video with 0.5s of the logo frame so the loop feels intentional.
